# Документация по Python интерфейсу для ZET 139

## Обзор

Данная документация охватывает два Python файла, которые предоставляют интерфейс для работы с трёхосевыми датчиками ZET 139 по Modbus RTU через USB:

- ```zet139.py``` - Основная библиотека-обертка для библиотеки ZET 139
- ```zet139_main.py``` - Пример приложения, демонстрирующий использование библиотеки

## Файл: zet139.py

### Назначение

Этот файл предоставляет Python обертку для библиотеки ZET 139, позволяя Python приложениям получать данные трёхосевых датчиков ZET 139.

### Основные компоненты

#### Структуры данных

- ```zet139_state```: Структура состояния датчика (метод ```get_state()``` возвращает её в виде словаря)
  - ```connected```: Статус подключения
  - ```frequency```: Номинальная частота дискретизации, Гц (float)
  - ```frequency_real```: Фактическая частота, Гц (float, 0 — ещё не прочитана)
  - ```serial```: Серийный номер
  - ```port```: COM-порт датчика

#### Основной класс: zet139

#### Инициализация

```python
def __init__(self, library_path=None)
```

Автоматически определяет подходящий файл библиотеки (.dll в Windows, .so в Linux) и загружает его. Если путь не указан, файл ищется в текущей папке, затем в ```build/``` и ```lib/``` (относительно текущей папки, а не папки скрипта).

#### Основные методы

- ```connect(serial=0)```: Найти датчик на USB и подключиться (0 — первый найденный); возвращает код результата
- ```disconnect()```: Остановить запись и отключиться
- ```get_state()```: Получить состояние датчика (словарь ```connected```, ```frequency```, ```frequency_real```, ```serial```, ```port```)
- ```get_channel_data(channel, data, size)```: Скопировать в ```data``` последние ```size``` отсчётов оси (0 - X, 1 - Y, 2 - Z)

Класс можно использовать как контекстный менеджер: ```with zet139() as sensor:``` — при выходе из блока ```disconnect()``` вызывается автоматически (```connect()``` при этом нужно вызвать самому).

#### Коды результата get_channel_data

- ```OK``` (0) — данные скопированы
- ```INVALID_SIZE``` (-3) — size равен 0 или больше буфера (5 секунд)
- ```NOT_ENOUGH_DATA``` (-4) — данных пока накоплено меньше size
- ```DISCONNECTED``` (-5) — связь с датчиком потеряна, идёт переподключение

Значения идут от старых к новым. На месте пропущенных отсчётов стоит NaN — при расчётах его нужно пропускать.

## Файл: zet139_main.py

### Назначение

Этот файл предоставляет полный пример использования библиотеки zet139 для получения данных с датчика ZET 139.

### Основные возможности

1. **Обработка сигналов**: Корректная обработка SIGINT (Ctrl+C) для graceful shutdown
2. **Подключение**: Автоматический поиск датчика на USB, серийный номер в hex можно передать аргументом
3. **Сбор данных**: Раз в секунду чтение последней секунды данных по каждой оси
4. **Обработка данных**: Вычисление среднего значения с пропуском NaN и печать фактической частоты датчика

### Основной workflow

1. Подключение к датчику
2. Получение состояния и номинальной частоты
3. Раз в секунду: печать фактической частоты и чтение данных по осям X, Y, Z
4. Обработка кодов результата (недостаточно данных, потеря связи, ошибка)
5. Отключение при завершении по Ctrl+C

## Пример использования

```python
from ctypes import c_float
from zet139 import zet139, OK

# Инициализация библиотеки
sensor = zet139()

# Подключение к первому найденному датчику
if sensor.connect() != OK:
    print("Не удалось подключиться к датчику")
    exit(-1)

# Состояние датчика и буфер на одну секунду отсчётов
state = sensor.get_state()
size = int(state['frequency'])          # частота — float, размер массива должен быть целым
data = (c_float * size)()

# Чтение последней секунды по оси Z
result = sensor.get_channel_data(2, data, size)
if result == OK:
    values = [v for v in data if v == v]    # пропускаем NaN
    print("Получена последняя секунда оси Z, среднее:", sum(values) / len(values))

# Очистка ресурсов
sensor.disconnect()
```

## Обработка ошибок

Библиотека предоставляет обработку ошибок через возвращаемые значения:

- ```connect()``` возвращает 0 (```OK```) или отрицательный код ошибки (-3 — датчик не найден, -4 — порт не открылся и другие, см. README библиотеки)
- ```get_channel_data()``` возвращает ```OK``` или один из кодов, перечисленных выше
- ```get_state()``` возвращает ```None``` при ошибке
- Выбрасывание ```FileNotFoundError```, если файл библиотеки не найден

## Поддерживаемые платформы

- **Windows**: Использует zet139.dll
- **Linux**: Использует libzet139.so

Библиотека автоматически определяет платформу и пытается найти соответствующий файл библиотеки в стандартных расположениях. Скрипты нужно запускать из папки ```example/python```, положив рядом собранную библиотеку: скопируйте ```zet139.dll``` (Windows) или ```libzet139.so``` (Linux) из папки сборки (```build```).

```bash
python zet139_main.py [серийный номер в 16-ричном виде]
```

## Зависимости

- Python 3.x
- Библиотека ctypes (стандартная библиотека)
- Библиотека ZET 139 (zet139.dll или libzet139.so)
